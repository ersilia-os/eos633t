# Extending molecular scaffolds with building blocks

MoLeR, a graph-based variational autoencoder from Microsoft Research and Novartis, extends a fixed scaffold with whole structural motifs rather than single atoms, so partially built molecules stay chemically sensible, and because generation is never conditioned on its own history it can complete arbitrary scaffolds. Training used GuacaMol's roughly 1.5 million drug-like molecules. Ersilia takes the Murcko scaffold of the input and decodes latent codes drawn from Enamine's 300k building-block library onto it, returning up to 100 distinct molecules. Sampling is unseeded, so repeated runs differ.

This model was incorporated on 2023-11-03.Last packaged on 2026-09-29.

## Use
To use this model locally, you need to have the [Ersilia CLI](https://github.com/ersilia-os/ersilia) installed.
The model can be **fetched** using the following command:
```bash
# fetch model from the Ersilia Model Hub
ersilia fetch eos633t
```
Then, you can **serve**, **run** and **close** the model as follows:
```bash
# serve the model
ersilia serve eos633t
# generate an example file
ersilia example -n 3 -f my_input.csv
# run the model
ersilia run -i my_input.csv -o my_output.csv
# close the model
ersilia close
```
